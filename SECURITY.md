# Security Policy

## Supported Versions

Borno Pulse is actively maintained. Security updates are applied to the latest version on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The Borno Pulse team takes security and user privacy seriously. As a local-first utility suite designed to monitor hardware and manage local files, we prioritize:
- Safe handling of system privileges
- Strict sandboxing and local-only network communications
- Redaction of sensitive credentials, tokens, and keys in clipboard and developer tools

If you discover a security vulnerability in Borno Pulse:

1. **Do not open a public issue.**
2. Send a detailed report via security advisory on GitHub or email the maintainers through [BornoSoft](https://bornosoft.bd).
3. Include reproduction steps, sample payload (if applicable), and affected macOS versions.
4. We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.

Thank you for helping keep Borno Pulse and its users safe!
